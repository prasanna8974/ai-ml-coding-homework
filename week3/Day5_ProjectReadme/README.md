**# Week 3 - Mini EDA Project**



**## Project Objective**



**The objective of this project is to perform basic Exploratory Data Analysis (EDA) on a student dataset using Python, Pandas, and Matplotlib.**



**The project analyzes student marks, study hours, attendance, and department information.**



**## Dataset**



**The dataset contains the following columns:**



**- Name**

**- Department**

**- Study\_Hours**

**- Attendance**

**- Marks**



**## Data Cleaning**



**The dataset was checked for:**



**- Missing values**

**- Duplicate records**

**- Correct data types**



**## Data Analysis**



**The following analysis was performed:**



**- Average marks**

**- Median marks**

**- Highest marks**

**- Lowest marks**

**- Students scoring above 80**

**- Average marks by department**

**- Correlation between numerical columns**



**## Data Visualization**



**The following charts were created:**



**1. Bar Chart - Student Marks**

**2. Histogram - Distribution of Student Marks**

**3. Scatter Plot - Study Hours vs Marks**



**## Key Findings**



**1. The dataset contains student academic information.**

**2. Average and median marks were calculated.**

**3. The highest and lowest marks were identified.**

**4. Students scoring above 80 were identified.**

**5. In this sample dataset, students with more study hours generally had higher marks.**



**## Technologies Used**



**- Python**

**- Pandas**

**- Matplotlib**



**## Conclusion**



**This project helped practice the basic EDA process, including loading CSV data, checking data quality, calculating statistics, analyzing categories, creating visualizations, and interpreting findings.**
